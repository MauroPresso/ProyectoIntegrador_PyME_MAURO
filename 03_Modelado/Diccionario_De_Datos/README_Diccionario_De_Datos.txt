README - Diccionario de Datos

La consigna del proyecto no exige un diccionario de datos formal como entregable separado.

Esta carpeta se mantiene con una version minima para apoyar la documentacion tecnica. Contiene un resumen de tablas y su objetivo, sin desarrollar un diccionario campo por campo.

Esto permite cumplir con la necesidad de documentar la estructura de la base de datos sin sobrecargar el proyecto ni desviarse del feedback del profesor de practica.
